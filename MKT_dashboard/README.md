# Online Marketing Performance — mkt Ecom

แดชบอร์ดรายงานผลการตลาดออนไลน์ พร้อมฟอร์มให้ทีมงานกรอกข้อมูลเอง
กรอกเสร็จกดบันทึก แดชบอร์ดทั้งหน้าคำนวณใหม่ทันที
รองรับหลายรายงาน แต่ละรายงานมีข้อมูลของตัวเองแยกกันสมบูรณ์

## วิธีเปิด

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องรันเซิร์ฟเวอร์
ทุก path เป็น relative จึงย้ายทั้งโฟลเดอร์ไปวางที่ไหนก็ได้

ต้องต่ออินเทอร์เน็ตเพื่อโหลด Chart.js กับฟอนต์ IBM Plex Sans Thai จาก CDN
ถ้าต้องใช้แบบออฟไลน์ ให้ดาวน์โหลดสองไฟล์นั้นมาไว้ใน `assets/vendor/` แล้วแก้ `<script>` กับ `<link>` ใน `index.html`

## โครงสร้างไฟล์

```
dashboard-mkt-ecom/
├─ index.html              โครงหน้าเว็บทั้งหมด ไม่มี CSS หรือ JS ปนอยู่ในไฟล์
├─ README.md
├─ DEPLOY.md              คู่มือติดตั้งระบบหลังบ้านทีละขั้น
├─ DEPLOY-VERCEL.md       คู่มือขึ้นเว็บสาธารณะบน Vercel
├─ vercel.json            ตั้งค่า Vercel
├─ api/
│  └─ sheet.js            พร็อกซีบน Vercel ที่เก็บ Token ไว้ฝั่งเซิร์ฟเวอร์
├─ backend/
│  └─ Code.gs             Apps Script ที่ทำหน้าที่เป็น API ให้ Google Sheet
└─ assets/
   ├─ css/
   │  ├─ base.css          ตัวแปรสี ฟอนต์ reset
   │  ├─ layout.css        แถบหัวเว็บ ปุ่ม แท็บ โครงหน้า
   │  └─ components.css    การ์ด KPI กราฟ ตาราง ฟอร์ม การแจ้งเตือน
   └─ js/
      ├─ app-config.js     URL และ Token ของหลังบ้าน กรอกหลัง Deploy
      ├─ api.js            คุยกับ Apps Script คิวบันทึก และสถานะการเชื่อมต่อ
      ├─ config.js         รายชื่อเดือน ช่องทาง ตัวสร้างรหัสระเบียน
      ├─ data.js           ข้อมูลตั้งต้นจากไฟล์ Report MKT online (25/8/2026)
      ├─ utils.js          ตัวช่วยจัดรูปแบบตัวเลข ตัวกรอง การแจ้งเตือน
      ├─ compute.js        derive() รวมตัวเลขทั้งหมดจาก STATE ที่เดียว
      ├─ charts.js         สร้างกราฟ 4 ตัว และปลั๊กอินเขียนตัวเลขกำกับแท่ง
      ├─ render.js         วาดทุกส่วนบนหน้าจอจากผลของ derive()
      ├─ forms.js          บันทึก แก้ไข ลบ และตรวจความถูกต้องของฟอร์ม
      ├─ reports.js        สร้าง สลับ เปลี่ยนชื่อ และลบรายงาน
      ├─ devtools.js       โหมดผู้พัฒนา นำเข้าและส่งออกข้อมูลเป็นไฟล์ .md
      └─ main.js           การนำทางระหว่างแท็บ และจุดเริ่มทำงาน
```

โหลด JS แบบ classic script เรียงตามลำดับข้างบน ไม่ได้ใช้ ES Module
เพื่อให้เปิดไฟล์ตรง ๆ ด้วย `file://` ได้โดยไม่ติด CORS

## การทำงานแบบหลายรายงาน

`REPORTS` เก็บรายงานทุกชุด แต่ละชุดมีข้อมูลครบ 5 ประเภทของตัวเอง
`STATE` คือข้อมูลของรายงานที่กำลังเปิดอยู่เท่านั้น การสลับรายงานจะแทนที่เนื้อใน `STATE` ทั้งชุด
โค้ดส่วนคำนวณและวาดหน้าจอจึงทำงานกับ `STATE` เหมือนเดิมโดยไม่ต้องรู้ว่ามีกี่รายงาน

ปุ่ม **สร้างแดชบอร์ดใหม่** มีสองแบบ

- **เริ่มจากว่างเปล่า** ได้แดชบอร์ดที่ยังไม่มีข้อมูลเลย รอกรอกจากฟอร์ม
- **คัดลอกจากรายงานที่เปิดอยู่** ได้สำเนาข้อมูลชุดเดิมพร้อมรหัสระเบียนใหม่ทั้งหมด แก้แล้วไม่กระทบต้นฉบับ

## โหมดผู้พัฒนา

ต่อ `?dev=1` ท้าย URL เช่น `index.html?dev=1` จะมีแผงเพิ่มขึ้นมาบนแท็บบันทึก Report
ใช้ลากไฟล์ `.md` เข้าไปเพื่อกรอกข้อมูลอัตโนมัติ แทนการนั่งกรอกฟอร์มทีละช่องตอนทดสอบ
ผู้ใช้ทั่วไปที่เปิดตาม URL ปกติจะไม่เห็นแผงนี้เลย

ตัวอ่านไฟล์รองรับตาราง markdown สองรูปแบบ

- **ตารางรวม** หนึ่งแถวคือหนึ่งระเบียน หัวคอลัมน์เป็นภาษาไทย
- **ทีละช่อง** สองคอลัมน์คือ `ช่องบนฟอร์ม` กับ `ค่าที่กรอก` หนึ่งตารางคือหนึ่งระเบียน

ระบบดูจากหัวคอลัมน์ว่าตารางไหนเป็นข้อมูลชุดใด ไม่ได้ดูจากลำดับหรือชื่อหัวข้อ
ตารางที่อ่านไม่ออกจะถูกข้ามไปเงียบ ๆ และสรุปผลการนำเข้าไว้ใต้แผง

ปุ่ม **ส่งออกรายงานปัจจุบันเป็น .md** ให้ไฟล์ที่นำเข้ากลับได้ทันที ใช้สำรองหรือย้ายข้อมูลระหว่างเครื่องได้

## ทางเดินของข้อมูล

```
ฟอร์มบันทึก → STATE (config.js/data.js) → derive() → render() → หน้าจอ
```

`STATE` มี 5 ชุด ตรงกับ 5 ชีทในไฟล์ต้นทาง

| ชุดใน STATE | ชีทต้นทาง |
|---|---|
| `mkt` | Facebook / Line |
| `sales` | ยอดขาย |
| `pipeline` | ยอดประมาณการ |
| `win` | WIN 100% |
| `ads` | ชีต2 (Ads Metrics) |

ทุกตัวเลขบนหน้าจอคำนวณจาก `derive()` ที่เดียว ไม่มีค่าไหน hardcode ไว้ใน HTML
ถ้าจะเพิ่ม KPI ใหม่ ให้เพิ่มใน `compute.js` แล้ววาดใน `render.js`

## กติกาการคำนวณที่ควรรู้

- **ยอดขาย** นับจาก `STATE.sales` แหล่งเดียว ช่องยอดขายในฟอร์มสรุป MKT เป็น read-only ที่ดึงมาแสดง เพื่อไม่ให้ยอดขายมีสองแหล่งที่ขัดกัน
- **ต้นทุนต่อ Lead และ ROAS** คิดเฉพาะเดือนที่บันทึกงบโฆษณาไว้แล้ว เดือนที่ยังไม่ลงงบจะไม่ถูกนำมาหาร
- **มูลค่าที่คาดว่าจะขายได้เดือน ส.ค.** แยกเป็น Facebook 2.42 ลบ. และ Line OA 6.25 ลบ. รวม 8.67 ลบ. เท่ายอดในชีทยอดประมาณการ ไม่นับซ้ำ
- **แถว พ.ค. ใน Ads Metrics** ค่าตามชีทต้นทางเรียงคอลัมน์ไม่ตรงกับเดือนอื่น (ช่อง Reach ได้ค่า 28.76 ซึ่งน่าจะเป็น CPM) ระบบแสดงตามชีทเดิมไว้ก่อน หากลูกค้ายืนยันหัวคอลัมน์แล้วให้แก้ค่าใน `assets/js/data.js` หรือกรอกทับในแท็บบันทึก Report
- **ปุ่มกลุ่มงานในกราฟอันดับ** สร้างจากข้อมูลจริง กลุ่มไหนยังไม่มียอดขายจะไม่มีปุ่มขึ้นมา
- **งบประมาณในแท็บ Ads Metrics** ใช้แสดงในตารางตัวชี้วัดสื่อโฆษณาเท่านั้น งบที่นำไปคำนวณต้นทุนต่อ Lead และ ROAS มาจากช่องงบประมาณ ADS ในแท็บสรุป MKT

## ข้อจำกัดของเวอร์ชันนี้

ถ้ายังไม่ได้กรอก `assets/js/app-config.js` เว็บจะทำงานในโหมดทดลอง ใช้ได้ครบทุกอย่างแต่รีเฟรชแล้วข้อมูลกลับเป็นค่าตั้งต้น
พอต่อหลังบ้านตาม `DEPLOY.md` แล้ว ข้อมูลทุกรายงานจะถูกเก็บใน Google Sheet และไม่หายอีก

ข้อจำกัดที่เหลือ: ถ้าสองคนแก้รายงานเดียวกันพร้อมกัน คนที่บันทึกทีหลังจะเขียนทับ
เพราะระบบบันทึกทั้งรายงานเป็นก้อนเดียว รายละเอียดอยู่ท้าย `DEPLOY.md`
