# คู่มือติดตั้งระบบหลังบ้าน

ระบบเก็บข้อมูลใช้ Google Sheet ของคุณเองเป็นฐานข้อมูล และใช้ Apps Script เป็นตัวกลางระหว่างเว็บกับชีท
ไม่มีค่าใช้จ่าย ไม่มีเซิร์ฟเวอร์ให้ดูแล และไม่มีการหลับเหมือนบริการฟรีบางเจ้า

ใช้เวลาติดตั้งประมาณ 10 นาที ทำครั้งเดียวจบ

---

## ขั้นที่ 1 — สร้างไฟล์ Google Sheet

1. เปิด [sheets.google.com](https://sheets.google.com) แล้วสร้างสเปรดชีตเปล่าหนึ่งไฟล์
2. ตั้งชื่อไฟล์ เช่น `ฐานข้อมูล Dashboard mkt Ecom`

ใช้บัญชี Google ของบริษัทที่ต้องการเป็นเจ้าของข้อมูล เพราะข้อมูลทั้งหมดจะอยู่ในไฟล์นี้

## ขั้นที่ 2 — วางโค้ดหลังบ้าน

1. ในไฟล์ชีท เลือกเมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดตัวอย่างที่ขึ้นมา (`function myFunction() {}`) ออกให้หมด
3. เปิดไฟล์ `backend/Code.gs` จากโปรเจกต์นี้ คัดลอกทั้งไฟล์มาวางแทน
4. กดรูปแผ่นดิสก์เพื่อบันทึก แล้วปิดแท็บ Apps Script

## ขั้นที่ 3 — สร้างแท็บและ Token

1. กลับไปที่ไฟล์ชีท แล้ว **โหลดหน้าใหม่หนึ่งครั้ง** จะมีเมนู **ระบบแดชบอร์ด** เพิ่มขึ้นมาบนแถบเมนู
2. เลือก **ระบบแดชบอร์ด → 1. สร้างแท็บเก็บข้อมูล**
   - ครั้งแรกจะมีหน้าต่างขออนุญาต ให้กด **ตรวจสอบสิทธิ์** แล้วเลือกบัญชีของคุณ
   - ถ้าขึ้นคำเตือน "Google ยังไม่ได้ตรวจสอบแอปนี้" ให้กด **ขั้นสูง → ไปที่ (ชื่อโปรเจกต์)** ซึ่งปลอดภัย เพราะเป็นสคริปต์ที่คุณวางเอง
   - จะได้แท็บใหม่ 6 แท็บ: Reports, MKT, Sales, Pipeline, Win, Ads
3. เลือก **ระบบแดชบอร์ด → 2. สร้าง Token ใหม่**
   - จะขึ้นรหัสยาว ๆ มาชุดหนึ่ง **คัดลอกเก็บไว้** เดี๋ยวต้องใช้ในขั้นที่ 5
   - ถ้าเผลอปิดไป เปิดดูได้ที่ **ระบบแดชบอร์ด → ดู Token ปัจจุบัน**

## ขั้นที่ 4 — เผยแพร่เป็น Web App

1. กลับไปที่ **ส่วนขยาย → Apps Script**
2. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
3. กดรูปเฟือง เลือกประเภทเป็น **เว็บแอป (Web app)**
4. ตั้งค่าดังนี้
   - **ดำเนินการในฐานะ (Execute as)** → `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)** → `ทุกคน (Anyone)`
5. กด **ทำให้ใช้งานได้**
6. คัดลอก **URL ของเว็บแอป** ที่ได้ หน้าตาประมาณ
   `https://script.google.com/macros/s/AKfycb.................../exec`

> ตั้ง "ทุกคน" เพราะเว็บต้องเรียกได้โดยไม่ต้องล็อกอิน Google การป้องกันใช้ Token แทน
> ใครไม่มี Token จะเรียกไม่ได้เลย

## ขั้นที่ 5 — ใส่ค่าลงในเว็บ

เปิดไฟล์ `assets/js/app-config.js` แล้วเติมสองค่านี้

```js
const APP_CONFIG = {
  apiUrl:   'https://script.google.com/macros/s/AKfycb.../exec',   // จากขั้นที่ 4
  apiToken: 'รหัสที่ได้จากขั้นที่ 3'
};
```

บันทึกไฟล์ แล้วเปิด `index.html` ใหม่ ถ้าตั้งค่าถูกต้องจะเห็นสถานะ **บันทึกแล้ว** สีเขียวบนแถบด้านบน
ข้อมูลตั้งต้นจะถูกส่งขึ้นชีทให้อัตโนมัติในการเปิดครั้งแรก

---

## การทำงานหลังติดตั้งเสร็จ

| สถานะบนแถบ | ความหมาย |
|---|---|
| โหมดทดลอง | ยังไม่ได้กรอก `app-config.js` ใช้งานได้แต่ข้อมูลไม่ถูกเก็บ |
| กำลังโหลดข้อมูล… | กำลังดึงข้อมูลจากชีทตอนเปิดเว็บ |
| กำลังบันทึก… | กำลังเขียนขึ้นชีท |
| บันทึกแล้ว | ข้อมูลตรงกับชีทเรียบร้อย |
| บันทึกไม่สำเร็จ | เขียนไม่ผ่าน กดปุ่ม **ลองใหม่** ที่อยู่ข้าง ๆ |

ระบบจะรวบการแก้หลายครั้งติดกันแล้วยิงขึ้นชีทครั้งเดียวหลังหยุดพิมพ์ประมาณ 0.7 วินาที
กรอกรัว ๆ สิบรายการก็เขียนขึ้นชีทรอบเดียว ไม่ทำให้ช้า

น้องที่เก็บรีพอร์ตยังเปิดชีทกรอกตรง ๆ ได้เหมือนเดิม แค่ต้องใส่ `report_id` ให้ตรงกับรายงานที่ต้องการ
ดูรหัสได้จากแท็บ `Reports`

## แก้ปัญหาที่พบบ่อย

**เมนู "ระบบแดชบอร์ด" ไม่ขึ้น**
โหลดหน้าชีทใหม่อีกครั้ง เมนูสร้างตอนเปิดไฟล์เท่านั้น

**สถานะขึ้น "บันทึกไม่สำเร็จ" ตลอด**
เอาเมาส์ชี้ที่ข้อความจะเห็นสาเหตุ ส่วนใหญ่เป็นสองอย่าง
- `Token ไม่ถูกต้อง` → คัดลอก Token ไม่ครบ ลองคัดใหม่จากเมนู ดู Token ปัจจุบัน
- `เซิร์ฟเวอร์ตอบกลับ 401` หรือ `403` → ตอน Deploy ตั้ง Who has access ไม่ได้เป็น Anyone

**แก้โค้ดใน Apps Script แล้วไม่มีอะไรเปลี่ยน**
ต้องกด **Deploy → New deployment** ใหม่ทุกครั้ง การกดบันทึกเฉย ๆ ไม่ทำให้ URL เดิมได้โค้ดใหม่
หรือใช้ **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชัน: ใหม่** เพื่อคง URL เดิมไว้

**ข้อมูลในชีทหายไปบางส่วน**
ระบบเขียนทับข้อมูลของรายงานนั้นทั้งชุดทุกครั้งที่บันทึก ถ้าแก้ในชีทพร้อมกับที่มีคนแก้บนเว็บ
ฝั่งเว็บจะเขียนทับ แนะนำให้เลือกทางใดทางหนึ่งต่อหนึ่งช่วงเวลา

---

## ข้อจำกัดที่ควรรู้

- **แก้พร้อมกันสองคนในรายงานเดียว** คนที่บันทึกทีหลังจะทับของคนแรก เพราะระบบบันทึกทั้งรายงานเป็นก้อนเดียว
  ทีมขนาดนี้แทบไม่เจอ แต่ถ้าต้องการแก้จริงต้องเปลี่ยนไปบันทึกทีละระเบียนพร้อมตรวจเวอร์ชัน
- **ความเร็ว** เขียนขึ้นชีทใช้เวลาราว 1-2 วินาทีต่อครั้ง เหมาะกับการกรอกรายเดือน
- **ความปลอดภัย** ป้องกันด้วย Token ระดับใช้ภายในองค์กร ถ้าต้องการให้ล็อกอินด้วยบัญชี Google
  ต้องเพิ่ม Google Sign-In ซึ่งเป็นงานอีกส่วนหนึ่ง
- **ขนาดข้อมูล** ถ้าโตเกินหลักหมื่นแถวจะเริ่มช้า ตอนนั้นค่อยย้ายไป Firebase หรือ Cloudflare D1
  โดยแก้แค่ `assets/js/api.js` ไฟล์เดียว
